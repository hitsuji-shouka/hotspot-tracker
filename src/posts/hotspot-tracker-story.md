## 一句话开局

整个项目始于一句话：「可以自己做个 GitHub 仓库网站吗，进行分类，并且追踪每天的热点项目」。

然后像滚雪球一样长出了 Skills 热榜、论文榜单、AI 新闻、财经看点、网址收藏、多端同步、每日推送，最后部署到了云服务器上。

## 踩过的坑

**1. 「今日热门」不是「今天创建」**

最初推送 GitHub 热门项目用 `created:>今天`，结果周末只抓到 3 个项目，榜首才 35 星。GitHub 的日期边界按 UTC 算，而且新项目根本来不及积累 Star。改成「近 3 天创建 + 按 Star 排序」后，榜首直接变成 1500+ 星的项目。

**2. 推送要增量，不要复读**

每天推同样的榜单没有意义。加了一个状态模块，每个任务记住推过什么，只推「距上次推送以来」的新面孔。

**3. 深色主题要全局启用**

shadcn 组件默认按亮色渲染，页面背景是手写的深色，结果 Tab 文字直接隐形。一行 `class="dark"` 解决，但发现它花了一次截图 review。

**4. 定时任务的工作目录和对话里不一样**

本地创建的自动化，早上定时跑的时候 cwd 变了，脚本路径全部找不到。教训：定时任务里永远用绝对路径。

## 经验

和 AI 结对开发最关键的不是「让它写代码」，而是**让它验证**：每次改完都构建、都在浏览器里截图看效果、都实际跑一遍定时任务。能跑通的交付才叫交付。
