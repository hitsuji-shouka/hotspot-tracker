## 起因

每天早上我的信息流是这样的：GitHub Trending 刷一遍、Hacker News 刷一遍、量子位刷一遍、财经快讯再刷一遍……半小时过去了，正事还没开始。

所以我和 AI 一起做了这个站的第一个版本：**热点追踪站**——把 GitHub 热门项目、Agent Skills、热点论文、AI 新闻、财经看点全部聚合到一个页面，每天早上定时任务自动更新，还会给我推送 Top10 榜单。

## 为什么又加了博客

追踪站解决的是「输入」问题，但我还缺一个「输出」的地方：

- 做项目过程中踩的坑，值得记下来
- 看到好文章想写点自己的评论
- 备案都备了，不放点自己的东西说不过去

于是就有了这个博客。文章都是 Markdown 写的，放在仓库的 `src/posts/` 目录里，构建时自动变成网页。

## 技术栈

- React + Vite + Tailwind + shadcn/ui
- 数据：GitHub API、skills.sh、Hugging Face Papers、量子位、Hacker News、新浪财经
- 部署：阿里云 ECS + 每日定时快照
- 协作：整个网站从第一行代码到部署上线，都是和 Kimi 一起完成的
