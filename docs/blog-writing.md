# 写一篇长文

在 `src/posts/` 新建一个 `.md` 文件，文件名就是文章网址中的 slug。下面的 `layout: essay` 会启用大标题、导语、双日期、读者提示框和正文首字放大；不写它时沿用普通笔记版式。

```md
---
title: 文章标题
date: 2026-09-25
updated: 2026-09-25
tags: [随笔, 技术]
summary: 用一两句话概括这篇文章。这段会显示在标题下方。
layout: essay
audience: 适合对这个主题感兴趣、想了解我的实践过程的读者。
---

这里直接写开篇段落，首字会自动放大。不要先写二级标题，才能得到截图中的开篇效果。

接下来照常写 Markdown 段落。只有你放进正文的图片才会显示。

## 第一个章节

正文……
```

`updated` 和 `audience` 都可省略。`date` 与 `updated` 使用 `YYYY-MM-DD`。`summary` 也用于博客列表的文章简介。

需要正文配图时，先把自己选定的图片放入 `public/blog/`，然后在文章中写 `![图片说明](../../public/blog/图片文件名.jpg)`。图片说明会显示在图下方。需要列表封面时，再在顶部添加 `cover: /blog/图片文件名.jpg`；留空就不会出现封面。视频、标题、列表、引用、代码块和表格仍使用普通 Markdown。
