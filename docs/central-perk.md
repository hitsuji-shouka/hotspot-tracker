# Central Perk

入口 `/lab/central-perk`，目录位于实验室「创作」。页面按需加载，使用现有 Three.js、OrbitControls 和原生 audio，不调用 AI 服务。

## 场景

`src/lib/central-perk-model.ts` 创建可旋转的真实几何场景：左后方转折吧台、商品展示格、橙色沙发、花纹木框椅、橄榄灰流苏扶手椅、绿色茶几、后排座椅和窗边高台。家具依据用户剧照；门面按后来提供的 LEGO 参考改为宽绿框窗、斜角棕色双扇门和红白遮阳篷。是风格化重建，非精确测绘。

`src/pages/CentralPerkScene.tsx` 管理渲染器、光照、相机过渡和拾取。店外保留屋顶/正立面，店内和俯瞰移除遮挡。点击沙发、杯子、咖啡机可聚焦并播放对应动作；也可以从场景设置中用键盘进入这些位置。右侧表演角有黑胶唱片机，点击实物播放/暂停；底栏黑胶入口是键盘替代路径。唱片转动和唱臂位置跟随实际 audio 播放状态。Home/双击复位，鼠标与触控可旋转缩放。

白天/傍晚/夜晚改变自然光强度、方向、颜色与室内灯。窗口另有投向街边的暖光，门板保留真实玻璃开口；VSM 柔化阴影，UnrealBloomPass 提供微弱灯光辉光。春夏秋冬改变树冠、屋顶积雪和街边粒子。移动端镜头按宽高比自动留出整个模型的空间。底栏与设置面板使用背景模糊玻璃材质。

`public/lab/central-perk/material-atlas.png` 为内置 image_gen 根据用户参考生成的四区贴图，用于墙饰、地毯和花纹椅；提示词保存在 `design/central-perk-material-prompt.txt`。概念稿只用作目录封面，场景不是图片投影。

## 背景音乐

默认 U2 — With or Without You，由用户提供的 MP3 构成，首次进入不自动播放。播放/暂停、音量、循环、离页停止均使用原生音频。服务支持 HEAD 与单范围 Range 请求。

从「场景设置 → 管理」使用网站已有管理口令解锁，之后出现「更换背景音乐」。支持上传 MP3（最大 20 MB）或填写 HTTPS 音频直链，编辑曲名、歌手、默认音量、循环，试听后保存。音乐平台详情页不能代替音频直链。

- `GET /api/cafe/music`：公开曲目配置。
- `POST /api/cafe/music`：管理员保存配置，含来源检查与参数验证。
- `POST /api/cafe/upload`：管理员上传 `audio/mpeg` 原始文件，验证 ID3/MPEG 帧头，返回媒体 URL。
- `GET/HEAD /api/cafe/audio/:uuid.mp3`：流式提供上传的音频，支持 Range。

复用 `ADMIN_PASSWORD` 和 `SITE_ORIGIN`。未配置口令时仍可看场景和播放默认音乐，管理界面只读。

默认持久化目录为服务文件旁的 `state/central-perk`（已被 Git 忽略），可用 `CAFE_DATA_DIR` 指向其他服务账户可写目录。配置文件为 `music.json`；上传使用随机文件名，保存配置时原子替换，不覆盖旧音频。该目录不位于 dist，常规部署不会替换它。需随网站其他持久化数据一起备份。多次换歌会保留历史文件，不自动清除。

部署包已加入 `server-cafe.mjs`。本地可运行 `npm run build` 后 `node --env-file-if-exists=.env server.mjs 8080`。有反向代理时将 `/api/cafe/` 转发给 Node，并允许不小于 20 MB 的请求体；若已有代理限制更低，上传会返回 413，前端保留旧配置。

## 检查

```sh
npm run build
node scripts/cafe-check.mjs
node scripts/admin-check.mjs
npx eslint src/pages/CentralPerkPage.tsx src/pages/CentralPerkScene.tsx src/lib/central-perk-model.ts
```

`cafe-check` 仅使用项目 state 下隔离临时目录，验证权限/来源、URL/音量、上传格式与体积、失败保留旧配置、Range/HEAD 和重启后的持久化。它不请求远程音乐，不消耗 API 额度。

浏览器验收：桌面与手机视角、拖动不会误点、昼夜/季节/物件动作、首次静音与实际播放进度、管理试听/保存/重新加载、返回实验室后音频停止。
